# Never Zero

Never Zero is a basketball win probability model designed to estimate live game win chances using score difference, time remaining, game format, possession, and scoring environment.

## Purpose

Traditional basketball win probability models are often designed around professional leagues. Never Zero was created to explore how probability modeling can be adapted for youth basketball environments while remaining usable for any basketball game.

## Features

- Quarter and half game formats
- Time-based probability adjustments
- Possession adjustments
- Scoring environment adjustments
- Live game situation analysis

## Built With

- HTML
- CSS
- JavaScript

## Project Goal

The goal of Never Zero is to combine basketball knowledge and programming to create a model that demonstrates how game situations influence win probability.
